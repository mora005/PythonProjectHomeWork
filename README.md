# Banking operations

## Описание проекта

Проект позволяет маскировать номер счёта и карты, а также форматировать дату в определённом (заданом по умолчанию) порядке. Может сортировать данные по ключам и датам.

## Установка

```

```

## Использование
### Функция ```filter_by_state ```
Функция принимает список словарей у которых ключ state соответствует указанному значению.
#### Пример работы
```
# Выход функции со статусом по умолчанию 'EXECUTED'
[{'id': 414288290, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
 {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
 ```
### Функция ```sort_by_date``` 
Функция принимает список словарей и необязательный параметр, отсортировывается по дате.
#### Пример работы
# сортировка по дате убывания
